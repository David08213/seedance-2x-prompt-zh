# 提示词验证与升级门槛

提示词更长、更专业或来源更热门，都不能证明生成效果更好。上游规则只视为候选假设；是否保留，要靠同条件对照生成。

## 最小A/B方法

1. 固定模型版本、画幅、总时长、参考素材、随机性设置和基础剧情。
2. A版使用当前提示词；B版只加入一个候选规则，例如“先写终态”“一镜一个移动者”或“触发后先停稳再推近”。不要一次加入全部规则。
3. 每版至少生成3次；重大项目建议5次。只挑最好的一条会放大运气。
4. 盲评时隐藏版本名，按同一张评分表比较平均表现和最差表现。
5. 规则只有在提高目标项、同时未明显损害人物或产品一致性时才并入默认工作流。

## 八项评分，每项0–5

| 项目 | 观察点 |
|---|---|
| 人物一致性 | 脸、发型、体型、服装在镜头内与跨镜头是否稳定 |
| 表演可信度 | 情绪是否有触发；眼神、呼吸、停顿是否像思考而非摆表情 |
| 戏剧转折 | 无声观看是否仍能看懂权力变化、误会或反转 |
| 空间连续性 | 左右关系、视线、进出方向、人物距离是否连贯 |
| 产品保真 | 颜色、轮廓、材质、logo位置和穿着状态是否服从参考 |
| 动作与物理 | 手脚数量、接触、布料受力、物件运动和终态是否合理 |
| 声音与对嘴 | 说话者是否正确；台词、停顿、口型和环境声是否协调 |
| 片段执行密度 | 关键片段是否具有独立导演意图、触发、双层表演、镜头响应和终态，而不是剧情概述 |

记录硬失败率：变脸、多人融合、产品变形、文字乱码、走位穿透、镜头方向反转、丝袜消失、敏感或不合规构图。平均分提高但硬失败率上升，不算升级成功。

## 快速验收

- 静音看一遍：还能理解主要关系和转折吗？
- 只听音轨：谁在说、情绪何时变化清楚吗？
- 逐帧看触发点：表情是否早于信息出现，或无原因突然切换？
- 截取首帧与尾帧：它们能否分别画成稳定构图，且下一段接得上？
- 放大产品：画面是在“证明一个卖点”，还是只让旁白声称？

## 片段升级判定

比较旧版与新版时，先遮住素材职责、全局不变量、画质词和负面词，只比较片段主体。满足以下条件才称为片段升级：

- 关键片段的唯一戏剧功能清楚，且不是一个片段承担多个大转折；
- 信息触发先于表情变化，至少一个关键镜头能看见“泄露后掩饰”或其他策略变化；
- 说话者与倾听者分工清楚，反应没有被台词和多人同步动作淹没；
- 摄影机行为与情绪转折有关，不是无理由套用推镜、环绕、85mm或浅景深；
- 尾帧明确，能够直接承接下一片段；
- 新版与旧版的差异发生在动作、表演、空间、镜头或产品证据上，而不只是字数、形容词和参数增加。

若只改了全局规则、参考绑定或防穿帮，而关键片段仍与旧版近似，应明确判为“全局架构升级、片段未升级”，继续重写片段，不要宣称整体已完成升级。

## 诊断原则

- 第一次失败：删掉互相冲突的动作、镜头或材质要求。
- 第二次失败：减少同镜人物和转场复杂度，固定首帧或尾帧。
- 同一镜头连续三次失败：更换镜头设计或拆镜，不继续堆字。
- 只在某次成功：视为偶然样本，不升级为默认规则。
- 写明结论的证据等级：官方文档、第三方经验、用户实测或尚未验证。
