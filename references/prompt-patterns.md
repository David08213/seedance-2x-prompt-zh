# 可复制的提示词模式

## 10秒多图产品广告

```text
【参数】10秒，9:16，写实电商广告。
【素材职责】逐张说明@图片用途。
【全局不变量】人物、产品、包装、场景、光线。
0–2秒：建立场景与产品，说明景别和推镜。
2–5秒：唯一核心演示动作，说明手部与材质响应。
5–8秒：微距或3D解释性展示，说明转场机制。
8–10秒：回到现实，人物或包装完成品牌落点。
【声音】环境音、动作音、旁白进入时点。
【一致性】只列高概率穿帮项。
```

## 15秒剧情对话

先计算台词长度。自然语速难以容纳时，明确建议拆段；若仍生成：

```text
0–3秒：冲突钩子，一个动作，一句短台词。
3–8秒：对方回应，镜头切近或跟随，不插入额外卖点。
8–12秒：产品介入，以一个可见动作证明一个卖点。
12–15秒：反应或福利落点，最后一帧明确。
```

对话逐句标注角色、语气、音量变化、停顿和同步动作。台词要求完全保留时，不改字，只调整分段。

## 长视频分段

Seedance单次生成不足以稳定承载长剧情时，拆成4–15秒片段。每段包含：

- 上一段尾帧状态；
- 本段唯一剧情任务；
- 人物、服装、道具、场景连续性锚点；
- 本段结尾动作，供下一段承接；
- 独立音频或后期配音建议。

不要让一个片段同时完成建立场景、复杂对话、换装、产品测试和品牌收尾。

长视频使用两层结构：全局母提示只锁定人物、服装、产品、场景和总导演原则；每个片段必须能脱离母提示成为一份可执行的小场戏。只扩写母提示、而让各片段继续停留在“谁说了什么、谁做了什么”的剧情概述，不算优化。

### 片段重写模板

```text
【片段总时长】只写本段总时长；用户不要秒点时不写内部时间码。
【唯一导演意图】本段只完成一个建立、逼迫、误会、揭露、反转、决定或余波。
【承接状态】上一段尾帧的人物位置、视线、手中物、服装和摄影机运动状态。
【空间关系】焦点人物、倾听者、相互距离、朝向、静态锚点和唯一移动者。

镜头一：功能与起始构图 → 触发 → 一个主动作或一句短台词 → 明确终态。
镜头二：切到真正需要被看见的反应；先写身体泄露，再写掩饰或策略变化；摄影机只做一种响应。
镜头三（确有必要时）：完成决定、产品证据或反转余波，不重复上一镜头的信息。

【声音】说话者、音量、语速、停顿的任务、动作声和环境声。
【尾帧】人物姿态、视线、手中物、产品位置、光线和下一段承接点。
```

片段之间不平均分配细节。冲突、认出、撒谎、揭穿、决定和产品证明镜头使用高表演密度；走路、进门、换场等桥接片段保持简单。升级时逐段比较旧版与新版，至少让关键片段在触发、微反应、策略、镜头响应或终态中出现实质变化，不能只替换形容词、焦段或“电影感”。

## 视频延长

```text
将@视频1向后延长X秒。承接原视频最后一帧的人物位置、行走方向、光线和镜头速度。
0–A秒：继续原动作，避免重新起步。
A–X秒：新增动作与镜头落点。
声音延续原环境，不突然换音乐。
```

生成时长只写新增部分。若向前延长，则以目标原视频首帧为结尾状态反推运动。

## 视频编辑或动作参考

明确哪些必须保留、哪些需要替换：

```text
参考@视频1的动作顺序、镜头高度和节奏；不复制其人物、剧情、服装和场景。
将主体替换为@图片1人物，产品外观服从@图片2。
```

“同款但不抄袭”时只抽取结构：钩子位置、笑点机制、镜头节奏和反转类型；重新设计台词、人物关系、场景和具体事件。

## 论文级描述的有效细节

增加能改变画面的信息：摄影机高度与相对位置、等效焦段倾向、移动方向、主体与镜头距离、主光方向、材质受力和恢复、背景视差、脚步落点、口播进入点、转场前后共享的形状或颜色。不要通过堆叠“高级、电影感、4K、极致、震撼”制造虚假精度。

论文级不等于总提示词很长。真正的提升应发生在局部镜头：演员为何停顿、眼睛在检查什么、双手正在完成什么任务、触发后哪个细节先失控、如何重新掩饰，以及摄影机为何在此刻停稳、推近或后退。
