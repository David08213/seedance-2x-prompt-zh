# 导演意图与真实表演

本文件用于剧情、对话、喜剧、暧昧、权力关系和情绪爆发。产品纯展示不必强行套入心理戏；产品若嵌在剧情里，只给人物段使用这些规则。

## 先读场，再写提示词

内部先回答以下问题，成稿不必逐项展示：

1. 本段唯一戏剧功能是什么：建立、逼迫、揭露、误会、反转、决定还是余波？
2. 观众此刻跟谁看、谁先知道、谁最后改变？
3. 权力从谁转给谁？用站位、距离、静止或视线如何看见？
4. 每个人此刻想从具体对象那里得到什么？写成动作动词，例如试探、逼问、拖延、讨好、遮掩。
5. 阻碍是什么？原策略何时失败，人物换成什么策略？
6. 台词与真实意图哪里相反？身体会泄露哪一个细节？
7. 拒绝哪种最俗套的处理？例如所有人同步惊讶、怒吼代表权威、慢动作代表高级。

把答案压缩成一句导演意图，例如：“让观众先相信她在认错，再从丈夫过早的微反应看出他在装睡，最终由她突然停止哭泣完成权力翻转。”此句统领表演、镜头、声音与剪辑。

## 可见行为链

每个主要镜头使用最短有效链条：

```text
起始状态 → 触发 → 不由自主的微反应 → 有意识的掩饰/策略 → 台词或动作 → 余波 → 终态
```

只选镜头真正需要的环节，不要强迫一个短镜头完整演完七步。没有触发就出现眼泪、怒火或大笑，会像“免费情绪”；没有余波，人物会在下一镜头情绪复位。

## 片段级表演密度

不要把细腻表演只写在全局总则里，期待模型自动分配到所有片段。每个关键片段要单独指定观众此刻跟谁看、哪句话或动作构成触发、身体先泄露什么、人物怎样试图掩饰，以及镜头最终停在哪里。普通桥接片段保持简洁，把文字预算留给真正发生策略变化的镜头。

关键片段通常由三种镜头职责组成，不要求机械齐全：

1. 说话或施压镜头：让焦点人物完成一句话或一个动作，听者只保留可见但克制的反应。
2. 反应镜头：在信息到达后才出现微反应，近景减少大动作，优先使用视线、呼吸、吞咽、下颌或手指停顿。
3. 决定或余波镜头：人物重新控制自己、改变策略或拒绝回应；为下一段留下可承接的身体状态。

升级旧提示词时，不保留“人物很生气地说”“镜头推进、氛围紧张”这类概述作为主体。把它改写成谁先停止手上任务、视线从哪里移到哪里、是否吞回一句话、音量如何改变、另一人何时意识到变化，以及摄影机为何在触发前后改变状态。只有加长全局说明、增加镜头参数或替换情绪形容词，不算表演升级。

## 表演写法

- 写目标，不写情绪结果：“想让他承认装睡”，优于“非常生气”。
- 写身体参数：重心高低、动作快慢、身体开放或封闭、呼吸高浅或低稳。
- 给双手一个简单任务，如叠衣、捏住床单、擦杯沿、整理包装。关键台词到来时突然停下手上任务，停顿就成为事件。
- 眼睛必须有任务：检查对方是否相信、躲开对视、偷看后立刻收回、在两个目标之间比较。眼睛先到，头部随后小幅转动；保持自然眨眼和清晰眼神光，但不要用死盯代替思考。
- 使用可观察动作描述眼部变化，例如“一次缓慢眨眼后重新对焦”或“视线先落向物件再抬回对方”；不要用眼睑百分比、肌肉角度等伪精确数字制造细腻感。
- 倾听从对方台词结束前开始；困难回答前保留能看见“决定”的短停顿。静默人物也要有任务，不能只是空脸等待。
- 一个短镜头只安排一个主表演动作或一个状态破口。近景动作更少，以视线、呼吸、下颌、吞咽和手指停顿为主。
- 表演需要策略变化。常见两拍：先维持体面，触发后泄露一瞬，再重新控制；或先讨好，失败后转为冷静威胁。
- 喜剧人物对荒唐处境保持认真；笑点由停顿、过早反应、错误掩饰和反应镜头产生，不靠挤眉弄眼。

## 多人物分工

为每位人物建立最小契约：身份标签、画面位置、朝向、目标对象、一个动作、一个表情泄露点、一个禁止项。

- 焦点人物完成唯一大反应；非焦点人物只保留呼吸、轻微眨眼、视线跟随或手上任务。
- 群体反应默认形成时间差：一人先意识到，另一人半拍后跟上，第三人不完全理解。只有刻意的喜剧齐拍才允许同步。
- 强势通常表现为更少移动、更慢回答、更长目光、更低音量；弱势常见碎动作、快速自触、填充笑和用眼神询问许可。状态反转时，让原本强势者出现一次短促破口，或让弱势者突然停止讨好。
- 人际距离本身就是台词：社交距离适合正式或戒备，个人距离适合谈判和信任，亲密距离只用于双方关系或明确的侵入行为。侍从、员工、陌生人等不得无理由贴近高位人物。

## 镜头与情绪同步

镜头不是独立炫技，它服务焦点人物的心理运动：

- 控制、权威、冷幽默：稳定机位或几乎不可察觉的呼吸感，保留人物的静止。
- 紧张、愤怒、失控边缘：小幅、低振幅、不规则的手持呼吸感；不要剧烈抖动。
- 震惊或认出：触发瞬间先短暂停稳，再极慢推近；不要一开始就推脸。
- 崩溃或需要空间：从中近景缓慢后退，让环境逐渐吞没人物。
- 喜剧揭穿：宽一点的稳定机位保持尴尬停顿；需要强调细节时才用一次短促推近或切反应。
- 暧昧与克制：稳定近景或过肩，微小呼吸和眼神变化；避免无缘由环绕。

情绪在同一镜头改变时，摄影机也分阶段改变，例如手持幅度随人物重新控制自己而逐渐收敛。摄影机移动幅度必须能达到所写终景；“微推10厘米”不能同时声称从全景变成眼部特写。

## 光线与声音

- 主光必须有场景内可信来源，面部补光只用于保持眼神和肤质可见。
- 声音跟随身体物理：急促呼吸不能配完全平稳长句；控制权上升时音量可以更低、语速更慢。
- 停顿必须包含评估、决定、拒绝或手上动作停止，否则是死空白。
- 关键台词与关键反应不要同时塞进同一张脸；先让说话者完成句子，再给听者反应，或让反应从句尾前轻微开始。

## 成稿自检

- 每个情绪是否有明确触发？
- 表演是否同时包含“想隐藏”与“没完全藏住”两层？
- 听者是否一直活着，但没有抢走焦点？
- 人物是否在结尾留下可承接的身体状态，而不是瞬间恢复中性？
- 去掉“高级、震撼、情绪拉满”后，剩余文字是否仍能拍出不同于普通模板的画面？
- 删除素材职责和全局总则后，关键片段本身是否仍能看出触发、双层表演、镜头响应和终态？若不能，说明升级仍停留在外壳。
