# 电商、丝袜与服饰展示

## 产品镜头的证据链

每个卖点由动作、镜头和结果组成：

```text
动作：手指轻压并抚过内里短绒。
镜头：微距侧光拍摄压痕和回弹。
结果：绒面恢复平整，未见明显飞絮。
```

避免只写“高级、亲肤、透气、耐穿”。模型需要看到卖点如何被表现。

## 丝袜材质锚点

- 超薄肉色：贴近肤色、低光泽、侧逆光可见连续细密纱线、膝弯延展、脚踝不堆积。
- 咖色或黑色：颜色均匀、哑光或指定光泽、膝盖和小腿色密度连续。
- 加绒：外层服帖，内里为实拍所示短绒；不要自动生成厚棉裤、长毛或毛毯质感。
- 裸感效果：写“远景接近自然肤感，近景能识别连续袜面纹理”，不要同时写“完全看不见丝袜”和“清楚展示丝袜”。

## 腿部展示镜头

人物明确为成年人。以穿搭和产品展示为目的，常用机位为正常视线高度的全身或侧面全景、膝上至鞋底的侧前方跟拍、小腿和脚踝微距。避免裙底视角、紧贴裆部、臀部中心构图或挑逗性动作。若主题是掉裆、卡裆等痛点，用中景衣物整理动作和面料状态表达，不依赖敏感部位极端特写。

## 体验与广告声明

| 营销方向 | 更可靠的画面表达 |
|---|---|
| 没有静电 | 摩擦后未见明显吸附、头发粘连、噼啪声或电弧 |
| 不勾丝 | 与光滑日常物体正常摩擦后袜面仍较平整 |
| 不掉裆 | 连续走动、坐起后版型仍贴合，人物无需频繁整理 |
| 防晒 | 强光户外仍保持覆盖感；具体指数仅在有检测依据时出现 |
| 磨皮美肤 | 视觉上肤色更均匀、腿部观感细腻，不声称治疗皮肤 |

## 包装与品牌

- 包装参考只负责实物外观，不让模型重新设计logo。
- 复杂中文、价格、福利和直播间引导优先用清晰口播或后期字幕；用户要求无字幕时，不让模型生成文字。
- “买一发二、拍一发三”等机制按用户本轮说法，不沿用历史版本。

## 现实到3D微观转场

使用四步：现实微距占满画面 → 纹理继续光学放大 → 无缝进入解释性CGI → 以同色同结构拉回现实。3D部分说明纤维排列、受力、回弹和接触关系，并明确为“结构示意”，不要伪造成显微检测报告。
